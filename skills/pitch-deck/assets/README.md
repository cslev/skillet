# assets

Optional personal defaults for an install in `~/.claude/skills/pitch-deck/`, so every project can use them without repeating paths:

- `template.pptx` (or any single `.pptx`): your organisation's template
- `logo.png` (or `.jpg`): your logo

The skill uses these only when no template or logo was named by you, named in the outline, or found in the project's `docs/`. Leave the folder empty if you don't want defaults.
